> **Poker Club** is an advanced Texas Hold'em Poker web application designed with a bright **Ludo White & Colorful** theme. Features clean white card backs, automated side pot calculations, AI strategy bot opponents, and real-time multiplayer room sync!

---

## ✨ Features

- 🎨 **Ludo White & Colorful Design**: White card backs, rich gold chips, crisp green felt tables, and clear pot indicators.
- 🧮 **Side Pot Calculator**: Automatically splits main pots and side pots accurately when all-in players are involved.
- 🤖 **AI Strategy Bots**: Practice against computer opponents with adaptive betting strategies (Passive, Aggressive, Balanced).
- 🌐 **Realtime Rooms**: Create private rooms, share room codes, toggle ready states, and play seamlessly.
- 🧪 **Unit Tested Engine**: 16/16 tests passing in Vitest for hand evaluation and pot logic.

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/AlfiMaulanaA/Poker.git

# Navigate into the project
cd Poker

# Install dependencies
npm install

# Run development server
npm run dev

# Run unit tests
npm test
```
